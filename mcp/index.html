Your agent, your computer

The One Dollar Computer MCP connects your own AI agent — Claude Code, Cursor, Codex, and more — to your One Dollar Computer account, so it can work with your firmware projects and lessons right from your chat.

Still in testing. We're putting this through its paces right now — it works, but expect rough edges, and things may change. Thanks for trying it early.

Copy. Paste. Done.

Copy this link and paste it into your favorite agent — or just type it there:

odc.rs/mcp

Click the link to copy it.

That's it. Your agent reads the page and does the rest — it will only ask you to approve once, with your Google login.

How the approval works

  1. Your agent starts. It installs the MCP server and asks to connect — you get one approval link.
  2. You approve with Google. Open the link in any browser, sign in with Google, and click Approve. No account yet? That first sign-in creates it, and you pick your username on the same screen. No new password, ever.
  3. Your agent is in. It sees the approval on its own and can start working. The pairing token lives on your machine, and you can revoke it any time from your page or Learn Physical AI.

What this page asks your agent to do — in the open

Nothing here is hidden. This page carries instructions for agents (in a comment at the top of the page, where agents look for them), and they say exactly this:

  1. Install the MCP server odc from the official npm package @onedollarcomputer/odc-mcp — nothing else, from nowhere else.
  2. Call odc_connect and show you the approval link it returns.
  3. Wait. Nothing connects until you approve.

What the agent gets — and what it doesn't:

  • On approval, the agent receives a token that works only with your One Dollar Computer projects and lessons.
  • The agent never sees your Google password. Sign-in happens on Google's own page, in your browser.
  • The token lives on your machine, and you can revoke it any time from your page.
  • If an agent ever asks for your password, or asks you to approve something you didn't start — stop. That is not this flow.

Set up your agent

You need Node.js 18 or newer. Then add the server — name it odc:

Claude Code 
claude mcp add odc -- npx -y @onedollarcomputer/odc-mcp

Want it in every project? Add --scope user.

Codex 
codex mcp add odc -- npx -y @onedollarcomputer/odc-mcp

Codex writes ~/.codex/config.toml for you.

Cursor 
{
  "mcpServers": {
    "odc": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@onedollarcomputer/odc-mcp"]
    }
  }
}

Paste into ~/.cursor/mcp.json, then switch odc on under Customize → MCPs.

VS Code (Copilot) 
{
  "servers": {
    "odc": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@onedollarcomputer/odc-mcp"]
    }
  }
}

Or use Command Palette → MCP: Add Server → Command (stdio) → npx -y @onedollarcomputer/odc-mcp. Note VS Code calls the key servers.

Any other agent 
{
  "mcpServers": {
    "odc": {
      "command": "npx",
      "args": ["-y", "@onedollarcomputer/odc-mcp"]
    }
  }
}

Most agents accept this mcpServers shape. Windsurf, Cline, Gemini CLI, Zed and Continue use the same command with small format differences.

After the server is added, just tell your agent: “Connect to my One Dollar Computer.” It calls odc_connect and hands you the approval link.

What your agent can do

Firmware projects: list, create, read, edit, publish and fork. Lessons for Learn Physical AI: list, create, read and edit. Board firmware is always complete Simple Rust (use odc::*;) — your agent gets the full authoring brief from the server itself.
