# SEO package

Extensible discoverability config for **One Dollar Computer** / **onedollarcomputer.com**.

| File | Edit when… |
|------|------------|
| `entity.json` | Brand facts, alternate names, official URLs change |
| `keywords.json` | New search queries to target |
| `sitemap.entries.json` | New public URLs |
| `analytics.json` | GA4 Measurement ID / Search Console verification |
| `generate_sitemap.py` | Regenerates `/sitemap.xml` |

Human playbook: [`docs/seo/README.md`](../docs/seo/README.md)
