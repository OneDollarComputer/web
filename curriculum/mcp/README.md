# odc-curriculum MCP

Stdio MCP for One Dollar Computer curriculum lessons.

See [../README.md](../README.md) for pair flow and Cursor/`mcp.json` setup.

**Agents:** after `curriculum_pair`, call `curriculum_agent_brief` (or read [../AGENT_LESSONS.md](../AGENT_LESSONS.md)). Teaching HTML5 is free; firmware for the board must be Simple Rust.

```bash
npm install
node bin.js   # normally launched by the MCP host
```
