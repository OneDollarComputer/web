ONE DOLLAR COMPUTER EDITOR — AI ASSISTANT INSTRUCTIONS This editor runs simple Rust firmware on the OneDollarComputer (board pins 0..=19). TO SEND CODE TO THIS EDITOR VIA LINK: 1. Write a complete simple Rust file using `use odc::*;` and `fn main()` (see sample). 2. Encode the source code as Base64. 3. Build the URL: https://EDITOR_HOST/index.html?code=BASE64_CODE 4. Share that URL with the user — opening it will load the code directly into the editor. STRICT OUTPUT RULES: - Prefer: use odc::*; fn main() { ... } - Board pins 0..=19 only (LED = 19, BUTTON = 13). - Do NOT write #![no_std], extern "C", or MCU pad names — the editor wraps bare-metal details. - Never put JavaScript, TypeScript, Firebase code, async functions, setTimeout, processBoardUpdate, or web-editor automation in the code parameter. JAVASCRIPT ENCODING (recommended approach for AI): const encoded = encodeURIComponent(btoa(unescape(encodeURIComponent(sourceCode)))); const url = `https://EDITOR_HOST/index.html?code=${encoded}`; PYTHON ENCODING: import base64 encoded = base64.b64encode(source_code.encode("utf-8")).decode() url = f"https://EDITOR_HOST/index.html?code={encoded}" SIMPLE RUST (preferred) — board pins 0..=19 ONLY: NEVER use MCU pad names (PD6, PC0, …) or gpio_pd* helpers — build rejects them. LED = pin 19. BUTTON = pin 13. use odc::*; pin_output / pin_set / pin_clear / delay Also: pin_high/pin_low/pin_read, led_on/led_off, read_button Bare-metal boilerplate is added automatically by the editor. BLINK EXAMPLE: use odc::*; // board helpers fn main() { pin_output(LED); // pin 19 as output loop { pin_set(LED); // LED on delay(200); // 200 ms pin_clear(LED); // LED off delay(200); } }
